==========================
SECURE SUBMISSION SYSTEM
==========================

Thank you for using the Secure Submission System!

GETTING STARTED
--------------
1. Double-click on "run_secure_submission_system.bat" to start the application
2. A web browser should open automatically. If not, go to http://localhost:5000
3. On first run, you'll be asked to create an admin account
4. Log in with your admin credentials
5. Create user accounts for team members
6. Users can then log in and start submitting content

FEATURES
--------
- Secure authentication with role-based access control
- Image and text submission system
- Review workflow for submissions
- Encrypted data storage
- User management for administrators

DATA STORAGE
-----------
All application data is stored in your Documents folder under "SecureSubmissionSystem".
This includes:
- The SQLite database (submission_system.db)
- Uploaded images

TROUBLESHOOTING
--------------
If you encounter any issues:

1. Make sure no other application is using port 5000
2. Try restarting the application
3. If the database becomes corrupted, you can delete it from the Documents\SecureSubmissionSystem 
   folder (note: this will erase all data)

For additional help, contact your system administrator.
